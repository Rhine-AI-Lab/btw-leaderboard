BenchtheWeights.Repair

Can an agent fix a broken networkby editing its weights?

Each of the 42 problems is a trained network with a hidden, hand-crafted bug, from image classifiers to speech and language models. The agent gets the weights, a dev set, 25 minutes and 50 forward passes. No gradients, no training. It solves a problem when it wins back at least 75% of the lost score on a hidden split.

Leaderboard

Ranked by problems solved, then by mean recovery. Two seeds per model, each a full pass over the problems, every model at its highest reasoning effort in its vendor's own coding agent.

      Contribute a problem

      A network with a hidden bug that is hard to spot and exactly repairable. If it passes our checks, it joins the next version of the benchmark with your name on it.

      It must pass four checks

      1. A repair without training restores the original score
      2. Least squares, low-rank fits and rescaling fail
      3. The dev set reveals the damage, but cannot fit the fix
      4. A frontier agent finds it neither trivial nor broken

      Build it with the open harness and keep it private until we publish it.
