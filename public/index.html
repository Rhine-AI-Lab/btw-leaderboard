Can an agent fix a broken network by editing its weights?

Each of the 42 problems is a trained network with a hidden, hand-crafted bug, from image classifiers to speech and language models. The agent gets the weights, a dev set, 25 minutes and 50 forward passes. No gradients, no training. It solves a problem when it wins back at least 75% of the lost score on a hidden split.

    Leaderboard

    Ranked by problems solved, then by mean recovery. Two seeds per model, each a full pass over the problems, every model at its highest reasoning effort in its vendor's own coding agent.

    Contribute a problem

    Send us a network and a bug that make a good problem: hard to spot, with no shortcuts, and exactly repairable. If it passes our checks we add it to the next version of the benchmark, with credit to you.

    Before you submit

    • Package the problem in our task format with the open harness, and check that it builds and scores
    • From 1 December, build and test it with our bug-injection pipeline and its three tests
    • Keep the corrupted weights and the write-up private until we publish the problem

    What we check

    • A repair without training brings the network back to, or near, its original score
    • Least squares, low-rank fits and rescaling do not fix it
    • The dev set is enough to find the damage, but not to fit the fix
    • One or two runs of a frontier agent, so it is neither trivial nor broken

    Evaluate a model

    Until the problems are public on 8 December, we run the evaluation for you, with the same harness, budget and 42 problems as every model on the leaderboard. We share the results with you, and they go on the leaderboard only if you agree.

    What we need

    • An API we can call, or open weights we can serve
    • Quota for two seeds of 42 trials, each up to 25 minutes
    • Ideally no retention of our traffic, since the agent sends weight statistics and code to the model

    From 8 December

    • The problems and the full pipeline are public, so you can run the benchmark yourself
    • Self-run results can be submitted with their trajectories, and are marked as self-run
