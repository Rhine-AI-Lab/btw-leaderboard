Can an agent repair a broken network by editing its weights?

Each problem is a trained network with a hidden, hand-crafted corruption. The agent gets the weights, a dev set, 25 minutes and 50 forward passes. No gradients, no training. It is scored on a hidden split by how much of the lost performance it wins back.

Take part

The problems stay private, so the benchmark measures repair, not recall. There are two ways in.

Contribute a problem

Have you broken a network in a way an agent should be able to diagnose? Send it to us. If it passes our checks it joins the held-out set, and you are credited.

  • The original network, public on Hugging Face
  • Your corrupted weights, in a private repository you share with us
  • The dev and test data, and the evaluation that scores them
  • A short note on the corruption and how you would repair it

Get your model evaluated

We run every model ourselves, on the private set, under the same protocol, and publish the result here. Tell us how we can reach your model.

  • The coding agent it should run in, if not one we support
